# Lessons: desktop release

guidance: desktop-release lessons v1

This file holds reviewed promotions only. Nothing lands here from a single run or an unreviewed
note. Each lesson is promoted after review and carries:
- Supporting outcomes: the runs or jobs it rests on, with their ids.
- Applicability: when it applies, and when it does not.
- Uncertainty: what is still unknown or unproven.
- Author and reviewer: who proposed it and who approved it, by name.
- Classification: what kind of failure it answers (runtime defect, evaluation defect, guidance
  gap, judgment miss). A runtime defect is fixed in the runtime, not written here as a rule.

Changing this file changes the guidance version recorded on each job; a mid-job change is noted in
the briefing and not applied silently.
